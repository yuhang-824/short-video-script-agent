# 用户、目标、范围和成功标准

面向短视频创作者，将主题、受众、平台、目标时长、风格转为有事实依据的可编辑脚本，让每个产品主张有出处、每镜有预计时长、风险与任务状态清晰。

交付为脚本，不是成片。合成P01仅写“产品支持字幕。”，不能推出自动识别、准确率、成本或效率数据。

## 核心范围

1. 核对五项输入；缺信息请求补充，不默认修改用户要求。
2. 素材检索与原文读取，保留素材ID、事实ID、原文、日期、内容指纹。
3. 三种结构生成标题、分镜、文字卡画面、旁白、字幕、额外停留时间。
4. 逐镜实际估时，检查事实、文案、画面、品牌禁词和平台要求。
5. 模型观察真实工具返回，决定补查、压缩、去停顿、安全修订、请求资料或停止；修改后旧检查失效。
6. 本机页面编辑并重新校验后导出JSON，人工校验与模型运行分别留档。

## 验收标准

| 要求 | 可观察的标准 |
| --- | --- |
| 正常生成 | 完整输入和素材下，本版时长与规则通过，输出分镜与引用 |
| 缺关键信息 | 返回具体缺失字段，不擅自补全 |
| 无素材 | 两种检索仍无事实则请求补充，不编造能力 |
| 工具失败 | 保留真实错误及已有草稿，不是completed |
| 超时修订 | 30秒目标实际38秒首稿→压缩→28秒重检通过 |
| 无法满足 | 2秒目标最短结构去停顿仍5秒，返回缺口3秒 |
| 事实追溯 | 主张的事实ID、原文、分镜和时长对应 |
| 更换结果 | 改语速、目标或原文，动作/分镜/时长随之变化 |
| 有界执行 | 达到上限时incomplete，不交付通过脚本 |
| 可编辑 | 编辑立即撤销旧批准；重检实际估时，拒绝无依据主张 |

## 非目标和限制

只覆盖合成中文短文、有限关键词/术语扩展、受限模板及原文事实。受众与风格保留为输出元数据，未实现丰富文案适配。新自由文案不做通用语义判断，可能保守拒绝正确改写。

未完成真实模型效果证明、实际素材真实性调查、向量检索、TTS、渲染、版权管理、生产认证或线上部署。时长为字符速率近似估算，目标是上限，不保证恰好相等。
